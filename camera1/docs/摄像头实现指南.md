## 当前功能

系统当前支持：
- `Map View` 中展示实时摄像头点位
- `Dashboard` 中展示事故相关摄像头证据
- `Route Planner` 确认导航后展示路线相关摄像头点位
- `Route Planner` 查看最近实时摄像头
- `Alert Detail` 中展示相关摄像头信息

## 数据来源

当前主要使用：
- data.gov.sg Traffic Images API
- OneMap / 公开地理数据辅助定位

## 事故与摄像头匹配

当前事故与摄像头匹配已迁到 Python 计算链路。

基本逻辑：
1. 获取实时事故
2. 获取实时摄像头
3. 计算附近摄像头
4. 返回合理距离内的匹配结果
