# FAST Frontend

This folder contains the browser UI served at `/`.

## Entry Files

- `index.html`: page markup and script/style entry point
- `manifest.json`: PWA manifest
- `mobile-location.html`: Android/mobile GPS upload page
- `assets/images/`: logos, map marker images, home images, member images and QR code
- `css/`: recommended CSS structure
- `js/`: recommended JavaScript structure
- `ml-traffic-model.js`: frontend ML helper used by alert details
- `sw.js`: service worker cache manifest for `/`
